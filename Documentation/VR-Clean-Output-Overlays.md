# Clean Output VR overlays — 2026-11-09

Open Clean Output… in the Player sidebar, check Include VR overlays (menus, editor and glove displays), and click Apply output. The choice is saved as CleanOutputOverlays in Settings/viewer.json. It defaults off, preserving scene-only captures until enabled. Clean Output itself must also be enabled, and VR must be running for the overlays to be visible.

The capture includes the application's currently visible VR overlays: task/Selections menus and cursors, the floating editor workspace including its captured popups, pose labels/range dial/appearance controls, glove LCDs, transport, calibration and Follow status. Hidden panels stay hidden. SteamVR's dashboard and overlays owned by other applications are not included. The regular main-window preview remains disabled while Clean Output is active.

Implementation: successful overlay operations publish their size, standing-space transform, visibility, sort order and the existing shared D3D11 texture handle. The output renderer imports those GPU textures and alpha-composites visible panels after its single scene render. Images are not captured back through the CPU, and the 3D scene is not rendered again. Panel height follows texture aspect ratio. Higher-priority overlays draw later; same-priority overlays are ordered by distance. The capture camera uses tracking-space transforms so panels remain aligned when locomotion moves or turns the viewer. The existing corrected flat-screen aspect/projection is retained. Panels outside the output frame can naturally be cropped.

Texture buffers continue using the existing persistent double-buffered overlay store. Imported views are reused while their underlying texture exists and released when no longer visible or when capture is disabled. An overlay-compositing error disables overlay capture for that renderer and reports it in the main status area, allowing scene-only output to continue; applying output again retries the requested setting.

Validation: Release publish and 46 focused Clean Output checks passed. GPU checks exercise shared texture import, alpha/color correctness, overlay sort priority, visibility changes, upright image orientation, panel movement, tracking-space head placement, back-face handling and resource cleanup. Existing output aspect, GPU scaling/resizing/fallback, settings serialization and updated settings-window layout checks also passed. The actual settings window preview was visually inspected. No full test suite or headset/OBS integration test was run. Verify the full composition on the gaming PC.

Install: close both VR applications and extract J5Studio-VR-Clean-Output-Overlays-update.zip over the existing portable VR folder, preserving subfolders. This is cumulative since Johnny5VR-0.9.0-cumulative-update-2026-11-08.zip and includes the previous aspect correction and Follow/menu changes. Existing Config, Settings, models and calibration are not overwritten; enable the new checkbox after updating.
