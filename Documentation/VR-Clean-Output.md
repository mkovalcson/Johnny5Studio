# Clean Output — 2026-11-09

Open Clean Output… in the VR Player sidebar. Leave Enable Clean Output unchecked for the existing desktop-preview behavior. To output elsewhere, enable it, select an active monitor, choose Windowed or Borderless fullscreen, set the render resolution (1920 × 1080 by default), and click Apply output. These options are saved separately from pending scene edits. The display list shows Windows monitor name, display device, current resolution, refresh rate and Primary status. Physical and virtual monitors use the same path. Refresh displays reloads the list.

The application keeps its controls and status in the main window. While Clean Output is active, a notice replaces the main 3D preview. The renderer produces one mirror view at the configured render resolution and presents it only to Clean Output. It does not render a duplicate main preview, does not share the image back into the main window, and does not transfer pixels through the CPU. A small GPU scaling pass fits the image into the output window, with black bars when aspect ratios differ. The VR headset still receives its two eye renders. The capture view follows a centered, aspect-correct camera at the headset position; excess headset coverage is cropped to fit the output rather than stretched. Both desktop mirror and Clean Output use this correction; Enable Include VR overlays to composite this application’s visible menus, editor, glove LCDs and other controls into the capture. SteamVR dashboard and third-party overlays are not included.

Fullscreen is borderless windowed presentation covering the selected monitor, not an exclusive display-mode switch. Configure the actual monitor resolution and refresh rate in Windows or Virtual Display Driver. The configured render resolution can differ from the monitor resolution and is fitted proportionally. With VR active, SteamVR continues pacing the render loop; the output does not introduce a second vsync wait. Without VR, the output presentation supplies desktop pacing.

The output is an independent, nonactivating window rather than an owned child window. Minimizing the main controls therefore does not minimize or stop the stream. Closing or disabling output, losing the selected display, or an output presentation failure releases its GPU surfaces and restores the main preview. The selected display uses its Windows monitor interface identity when available, so missing displays are not silently replaced by another monitor. A display that disappears disables Clean Output; use the selector to re-enable it when available again.

OBS: select the virtual monitor with Display Capture, or capture the separate J5 Studio VR · Clean Output window with Window Capture. Keep the main Viewer controls and OBS on the primary display. OBS frame rate and audio capture remain separate settings. This change does not install or configure Virtual Display Driver. For your headset setup, configure that virtual monitor to 1920 × 1080 at 75 Hz before selecting it. Clean Output remains a usable independent window on a physical monitor too.

Settings are stored in the Player's Settings/viewer.json: CleanOutputEnabled, CleanOutputDisplay, CleanOutputFullscreen, CleanOutputWidth and CleanOutputHeight. Defaults leave Clean Output off; render resolution defaults to 1920 × 1080 and the output mode defaults to borderless fullscreen. Applying output remembers the choice across launches. Saved movie-scene changes preserve the active output settings.

They cover defaults and serialization, display enumeration, aspect fit/letterboxing, independent window bounds, the actual D3D11 output texture/blit pixels, output resizing, disabling output and resuming the desktop presentation path, plus settings-window layout. Physical virtual-monitor unplug/replug, OBS capture and headset pacing at 75 Hz still need testing on the gaming PC.

Install: close both VR applications, then extract J5Studio-VR-Clean-Output-update.zip over the existing portable VR folder, retaining subfolders. This is cumulative since Johnny5VR-0.9.0-cumulative-update-2026-11-08.zip and includes previous menu/Follow/laser corrections. Config, models, existing Settings and saved calibration are not shipped or overwritten. The regular Desktop Editor is not deployed.
