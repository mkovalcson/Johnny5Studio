# VR pose upper banks and dial placement

The dial opens above the viewer-right side control bank. Its center is aligned
with that bank, and its surface is on exactly the same depth plane as every
control label. Its lower edge clears the head and side labels. The dial remains
in this stable location while posing rather than appearing close to the headset.

Central body controls are in a centered column above the head. X, Y and heading
placement controls remain in that column. All ganged controls, including hand
gangs, occupy an upper-left column. Its left edge aligns exactly with the left
edge of the viewer-left side bank. Both upper groups extend upwards to fit.

All three label groups use identical physical widths/heights and the same text
renderer, with icons to the left. Side controls retain anatomical height order
and shoulder-to-track spacing. All 81 actual model controls remain available.
Loading feedback and asynchronous graphics preparation remain active.
