# Johnny 5 Studio

This repository contains J5 Studio Desktop, VR Player and VR Editor. Start with
[Development setup](DEVELOPMENT.md), [test fixtures](TestFixtures/README.md) and
[project documentation](Documentation/README.md). User Help is available in either editor.
The deployable Config template includes the full-body Johnny 5 model and a TipToe demo.

## Platform and requirements

J5 Studio Desktop, VR Player, and VR Editor are Windows applications built with .NET 10.
To build from source, install the .NET 10 SDK on Windows and follow the
[development setup](DEVELOPMENT.md). Self-contained Desktop Full and VR Full
packages bundle the .NET runtime. VR use requires SteamVR.

- [Desktop system requirements](Shared/UserHelp/DesktopSystemRequirements.md)
- [VR system requirements](Shared/UserHelp/VrSystemRequirements.md)
